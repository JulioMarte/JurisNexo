# SCJ Parser Gold Dataset v1

This directory defines the first independently reviewed accuracy dataset for the JurisNexo SCJ parser.

It is deliberately separate from the full-corpus coverage profiler. A parser run processing every page or matching a publication's declared decision count is useful structural evidence, but it is not a precision/recall measurement.

## Current status

`annotation_in_progress`

No file in this directory should be described as gold merely because it was generated by the production parser. A row becomes eligible for accuracy evaluation only after a reviewer verifies the cited primary-source pages and marks it `reviewed` or, after disagreement resolution, `adjudicated`.

## Required layout strata

The v1 sample covers these observed production families:

- `principales_2023_2024_sentence`
- `principales_2023_2024_resolution`
- `principales_2025_primera_sala`
- `principales_2025_segunda_sala`
- `principales_2025_tercera_sala`
- `principales_2025_pleno_resolution`

The manifest contains the release-sample minima. Rare resolution families have explicit lower per-family minima, but the overall minimum remains 60 reviewed cases. These are engineering gates, not statistical confidence claims.

## Annotation unit

One row represents one judicial-decision span in one immutable source artifact.

Required identity fields:

```json
{
  "schema_version": 1,
  "review_status": "pending",
  "artifact_id": "sha256-or-stable-artifact-id",
  "source_filename": "official-compilation.pdf",
  "source_sha256": "...",
  "start_page": 10,
  "end_page": 14,
  "layout_family": "principales_2023_2024_sentence"
}
```

Gold fields are independently reviewed values:

```json
{
  "annotated_fields": ["decision_number", "decision_date", "court_organ"],
  "decision_number": "SCJ-PS-25-0001",
  "docket_numbers": ["..."],
  "decision_date": "2025-01-31",
  "court_organ": "Primera Sala"
}
```

A field omitted from `annotated_fields` is **not reviewed** and must not enter that field's denominator. A field present in `annotated_fields` with a null/empty gold value means the reviewer explicitly verified absence.

## Parser suggestions

Annotation packets may contain a separate `parser_suggestion` object to help reviewers navigate the source efficiently. It is never gold evidence and must not be copied blindly into reviewed fields.

Example:

```json
{
  "parser_suggestion": {
    "decision_numbers": ["SCJ-PS-25-0001"],
    "docket_numbers": ["..."],
    "decision_dates": ["2025-01-31"],
    "court_organs": ["Primera Sala"],
    "diagnostics": []
  }
}
```

The evaluation runner ignores this object.

## Review protocol

1. Open the immutable primary artifact identified by `artifact_id` / `source_sha256`.
2. Verify the proposed start and end physical pages. Do not infer a boundary only from parser output.
3. Record the correct layout family from the observed publication grammar.
4. Verify each annotated metadata field directly against the primary-source pages.
5. Preserve uncertainty by leaving a field unannotated rather than guessing.
6. Set `review_status` to `reviewed` only after primary-source verification.
7. If two reviewers disagree on a material boundary or field, keep the row out of gold until adjudication; the resolved row uses `adjudicated`.

## Hard-case sampling

The packet builder prioritizes cases with parser diagnostics in addition to deterministic coverage across each family. The reviewed set must therefore include both ordinary and adversarial examples; a dataset containing only clean headers is not sufficient for a promotion decision.

## Evaluation

Once reviewed rows exist, produce current-parser predictions as a separate JSONL and run:

```text
python benchmark/ingestion/evaluate_scj_parser_gold.py \
  --manifest benchmark/ingestion/gold/scj-parser-v1/manifest.json \
  --gold <reviewed-gold.jsonl> \
  --predicted <current-parser-predictions.jsonl> \
  --output <evaluation-report.json>
```

Use `--enforce-gate` only when this dataset has been explicitly designated a release gate. Until sample minima are satisfied, `insufficient_sample` is the correct result and must not be relabeled as pass or fail.

## Versioning

Do not mutate a locked reviewed dataset in place after it has been used to approve a parser release. Corrections require a new dataset revision with documented provenance. Parser predictions and evaluation reports are generated artifacts; human-reviewed labels are versioned evidence.
